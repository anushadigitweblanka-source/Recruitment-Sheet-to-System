# duplicate-risk-reports/

Reports on likely duplicate candidates found in the source sheet or the system: the matching rule used, the suspected pairs, and the resolution decided for each.

- One report per run, named with the date (e.g. `2026-10-14-duplicates.md`).
- For each suspected pair record: the fields that matched, the confidence, the decision (merge, keep both, reject), who decided, and when.
- These reports may reference real people — treat the folder as confidential and keep it out of any shared or published output.
