# prompts/

Reusable prompts for AI-assisted work on this task: build prompts, review prompts, and analysis prompts that produced good results.

- Save a prompt together with a one-line note on what it is for and when to use it.
- Version by filename when a prompt is revised (e.g. `build-skeleton-v2.md`); keep the old one until the new one is proven.
- Prompts must not contain credentials or real personal data.
