# validation/

Checks that the system behaves as specified: test plans, manual test checklists, test results, and data-verification reports.

- One file per validation run, named with the date and scope (e.g. `2026-10-14-offers-module.md`).
- Each check records the input, the expected result, the actual result, and pass/fail.
- Failures get a short note on the cause and a link to the fix once made.
