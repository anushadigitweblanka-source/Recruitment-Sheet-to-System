# evidence/

Proof that work was actually done and verified: screenshots, terminal output, test-run logs, health-check responses, and before/after captures.

- One subfolder or filename prefix per task step or date (e.g. `2026-10-14-login-flow/`).
- Every claim made in `documentation/` or `closure/` should have a matching item here.
- Never store credentials, `.env` contents, or real personal data in screenshots.
