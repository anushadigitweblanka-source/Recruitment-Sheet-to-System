# capability/

Records of what access and tooling this task has: connectors, databases, accounts, and environments that have been confirmed to work.

- One entry per capability: what it is, how it was verified, the date, and any limits (e.g. read-only).
- Also record what is NOT available or still awaiting approval, so nobody re-tests it.
- Never store passwords, tokens, or connection strings here — only where they are configured.
