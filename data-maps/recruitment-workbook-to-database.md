## 8. Date / datetime normalization rules (apply to every date column above)

| Source form                                                                        | Handling                                                                                                                  |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| True Excel date/time cell                                                          | NORMALIZE: convert from the Excel serial value to `date` / `timestamptz`; never via the displayed text                    |
| Text date, unambiguous format                                                      | NORMALIZE after the tab's date format is confirmed; one confirmed format per column, not per row                          |
| Text date, ambiguous (e.g. 03/04/2025 where day/month order is unknown)            | REVIEW REQUIRED — never guess                                                                                             |
| Date-with-time values (interview slots)                                            | NORMALIZE to `timestamptz`; wall-clock times are Asia/Colombo, stored with that zone                                      |
| Deadline-style dates feeding reminders                                             | end date at 17:30 Asia/Colombo (the confirmed Module 6 rule) — but reminders are NOT created for imported historical rows |
| Malformed / impossible dates (e.g. 31/02, year 1900 artifacts, blank-but-required) | REVIEW REQUIRED with issue `invalid_date`                                                                                 |

No date is ever invented or defaulted; a missing required date sends the row to review.
